> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish Orca v0.3.10 as a small, complete TUI reliability release for the runtime-owned interaction rail, durable Goal approvals, and nonblocking session discovery.

**Architecture:** The release contains four already integrated semantic commits: TUI interaction/event projection uses the runtime surface as its single owner, Goal admission no longer consults the process-local pending store, Goal approval settlement is typed and durable, and session discovery/history opening accepts only safe regular transcripts. Release preparation changes metadata and documentation only; the GitHub tag workflow remains the sole binary and npm publisher.

**Tech Stack:** Rust/Cargo, Node.js release verifiers, Vite website, GitHub Actions, GitHub Releases, npm.
