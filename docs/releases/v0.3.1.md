# Orca v0.3.1

Orca v0.3.1 makes saved conversations and active-session management a single,
predictable TUI workflow, with explicit recovery decisions and copyable resume
commands.

## What Changed

- `/resume` is now the only saved-session slash command. Its picker supports
  resuming, forking, renaming, archiving, deleting, and copying a session ID.
  The former `/history` command is no longer exposed.
- `/new` starts a clean conversation. `/clear` remains a hidden compatibility
  alias for `/new`, while `Ctrl+L` only clears the terminal display.
- `/fork [name]` creates a durable child session with the current conversation
  context, and `/rename [name]` updates the active session title. Session
  switching starts the replacement runtime before closing the source session,
  so a failed switch does not discard the current conversation.
- `/status` reports the current session, model, approval mode, working
  directory, and runtime state. `/copy [N]` copies the Nth most recent finalized
  assistant response through the existing clipboard path.
- Recoverable operations are no longer resumed implicitly by `/resume`. The TUI
  presents an explicit Continue or Cancel decision bound to that operation.
- Exiting a persisted session prints `orca --resume <SESSION_ID>`, matching the
  command accepted by the CLI. `orca --fork [SESSION_ID]` remains available for
  starting from an existing conversation without modifying it.

## Compatibility

Existing saved conversations remain readable. Scripts using the public
`--resume` and `--fork` CLI flags remain compatible. `/history` users should
switch to `/resume`; `/clear` continues to work as an undocumented alias for
`/new`.

## Upgrade

```bash
npm install -g @blade-ai/orca@0.3.1
```

macOS and Linux native installer:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.3.1 sh
```

Windows PowerShell, including workspace sandbox setup:

```powershell
& ([scriptblock]::Create((irm https://orcaagent.dev/install.ps1))) -Version 0.3.1 -SetupSandbox
```
