# Orca v0.3.4

Orca v0.3.4 fixes context-window observability and replaces the fixed
96,000-token compaction default with a model-window-aware policy.

## What Changed

- The TUI context meter now reports used context against the model's full
  context window. After each model response it uses the provider-reported
  prompt token count instead of cumulative session usage or a local estimate.
- Automatic compaction now derives its default trigger from the model window:
  80% for the normal trigger and a 90% hard safety ceiling. A 1M-token model
  therefore compacts near 800k instead of prematurely compacting near 96k.
- Compaction keeps a fixed recent-context budget of about 48k tokens before
  summarizing older history. The retained tail no longer grows linearly with a
  large model window, and compaction lands far enough below the trigger to
  avoid repeated compaction on consecutive turns.
- Existing `soft_compact_token_limit` and `auto_compact_token_limit`
  configuration values remain supported as explicit absolute overrides.

## Compatibility

CLI flags, configuration file syntax, saved sessions, JSONL, app-server, ACP,
and provider wire contracts remain compatible. Existing absolute compaction
overrides retain their previous meaning; only the default policy changes.

## Upgrade

```bash
npm install -g @blade-ai/orca@0.3.4
```

macOS and Linux native installer:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.3.4 sh
```

Windows PowerShell, including workspace sandbox setup:

```powershell
& ([scriptblock]::Create((irm https://orcaagent.dev/install.ps1))) -Version 0.3.4 -SetupSandbox
```
