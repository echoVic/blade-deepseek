# Orca v0.3.6

Orca v0.3.6 makes delegated execution and durable task state observable and
safe across process boundaries.

## What Changed

- Added a serializable DelegationSnapshot so synchronous and asynchronous
  child agents inherit the parent approval mode, permission profiles, workspace
  roots, permission rules, additional working directories, and model selection
  through one explicit contract.
- Reworked thread transcript writes around a stable sidecar lock. Appends,
  metadata read-modify-rewrite operations, compression, and atomic transcript
  replacement now share the same cross-process critical section.
- Task summaries now persist provider retry counts and truncated-output state.
  Prompt-too-long compaction retries and normal or read-only tool truncation
  publish updated task summaries, so failures and degraded output remain
  visible after reload.
- Session completion publishes the complete task registry before
  session.completed, preserving the distinction between a finished foreground
  turn and still-running or approval-blocked background work.
- The typed runtime surface and TUI projection carry the new task diagnostics
  with backward-compatible defaults for existing records.

## Compatibility

Existing CLI flags, configuration files, saved sessions, JSONL, app-server,
ACP, and provider wire contracts remain compatible. Existing task and surface
records without retry or truncation fields load as zero/false. The release
adds diagnostic fields without changing task identifiers or terminal status
names.

## Upgrade

~~~bash
npm install -g @blade-ai/orca@0.3.6
~~~

macOS and Linux native installer:

~~~bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.3.6 sh
~~~

Windows PowerShell, including workspace sandbox setup:

~~~powershell
& ([scriptblock]::Create((irm https://orcaagent.dev/install.ps1))) -Version 0.3.6 -SetupSandbox
~~~
