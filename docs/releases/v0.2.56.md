# Orca v0.2.56

Orca v0.2.56 tightens the boundary between the `orca` executable and its
libraries, completes stateless JSONL turn ownership, and hardens macOS Seatbelt
enforcement. The public CLI and protocol shapes remain compatible while command
and lifecycle behavior move behind explicit runtime-owned APIs.

## What Changed

- The root binary is now limited to CLI parsing and forwarding. Effective
  configuration, launch, update, history, trust, workflow commands, protocol
  startup, and worker execution are owned by `orca-runtime` or `orca-tui`
  library surfaces instead of duplicate modules under `src/`.
- A source-level architecture contract prevents command behavior from moving
  back into the binary. ACP keeps its typed ownership boundary, and command
  output or trust persistence failures now propagate instead of being reported
  as successful execution.
- Stateless JSONL submissions no longer require a persisted thread record.
  Runtime-owned ingress, operation identity, interaction routing, completion,
  and cleanup now cover the entire turn, including cancellation and settlement
  when stdin reaches EOF.
- macOS sandbox execution now invokes `/usr/bin/sandbox-exec` directly, passes
  filesystem roots through Seatbelt parameters, normalizes missing descendants
  against their nearest existing ancestor, and shares one embedded base policy
  across read-only and workspace-write modes.
- Seatbelt write access is limited to the workspace and explicit protected
  metadata roots. Denied roots keep precedence, Unix socket and network access
  remain policy-controlled, and a missing enforcement backend fails closed
  rather than silently running the command outside the sandbox.
- Shell sessions, direct server commands, workflow commands, and runtime tool
  execution now use the same sandbox contract and carry the effective sandbox
  state through their typed boundaries.

## Compatibility

No CLI flag, configuration, or JSONL wire-format migration is required.
Existing persisted threads and sessions remain readable. On macOS, commands
that request a sandbox now fail explicitly if Seatbelt cannot be enforced;
`danger-full-access` remains the explicit unrestricted mode.

## Install

```bash
npm install -g @blade-ai/orca@0.2.56
```

Or install a native release asset:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.2.56 sh
```
