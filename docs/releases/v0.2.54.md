# Orca v0.2.54

Orca v0.2.54 completes the production TUI migration onto the runtime-owned
typed surface. The TUI is now a client of one durable runtime truth for turns,
interactions, cancellation, terminal settlement, projection, and restart
recovery.

## What Changed

- The production app loop, agent runtime, and action dispatcher now carry one
  `TuiSurfaceTaskControl`. The legacy operation controller remains only at
  explicit compatibility and test boundaries; it no longer owns production
  turn, Goal, workflow, or interaction routing.
- Ordinary TUI submissions reserve and admit a typed runtime operation before
  execution. User, assistant, reasoning, tool, usage, context, task, and
  terminal facts are committed as durable surface batches before the renderer
  observes them.
- Tool approval, permission, user-input, and MCP elicitation responses stay
  bound to the exact operation and generation. Resolution is persisted before
  a provider waiter wakes, and cancellation atomically records both the
  control intent and interaction terminal.
- Foreground/background handoff, task stop, Goal controls, and workflow
  lifecycle use the same runtime-owned command and projection path. The TUI no
  longer reconstructs an independent lifecycle from raw runtime events.
- Terminal delivery waits for runtime cleanup and the durable terminal cursor.
  Manual compaction now emits its visible completion only after surface
  finalization; missing terminal authority fails closed instead of displaying
  a false success.
- Restart attaches through snapshot plus cursor replay, restores exact
  operation ownership and pending interactions, redacts private state before
  waiter release, and never re-executes an already committed generation.
- Goal turn failures and panics now settle the owned outer turn and pause
  safely, preventing an in-flight Goal from being stranded by a failed
  generation.

## Compatibility

No CLI flag or user configuration change is required. Existing recorded
sessions, Goal state, task state, and workflow records remain readable.

This release intentionally completes the TUI milestone first. ACP typed-surface
convergence continues after the published TUI release, followed by JSONL
compatibility work.

## Install

```bash
npm install -g @blade-ai/orca@0.2.54
```

Or install a native release asset:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.2.54 sh
```
