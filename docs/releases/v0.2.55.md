# Orca v0.2.55

Orca v0.2.55 completes the runtime-owned typed-surface convergence for ACP and
the JSONL server after the production TUI milestone shipped in v0.2.54. All
three surfaces now submit commands to the runtime and observe durable typed
state instead of rebuilding operation, interaction, terminal, or recovery
ownership in their adapters.

## What Changed

- ACP session admission, prompt reservation and binding, attachment lifecycle,
  cancellation, terminal gating, and capability settlement now run through a
  bounded runtime supervisor. A prompt response is not written until replay and
  the durable terminal cursor have been flushed to the client.
- ACP load and resume attach from a runtime snapshot plus cursor, preserve the
  exact operation and generation identity, and settle read, write, permission,
  and elicitation capabilities before retiring the transport.
- The JSONL server now uses one `JsonlSurfaceAdapter` for thread, turn, control,
  permission, user-input, and MCP-elicitation routes. Legacy server-side
  operation and interaction owners have been deleted from production paths.
- JSONL requests keep exact opaque identities and owner-bound response
  authority. EOF and transport shutdown settle pending routes without
  reclassifying committed work, and restart recovery reattaches through the
  runtime journal instead of reconstructing a second lifecycle.
- Differential fixtures preserve the public v0.2.50 JSONL request and event
  shape while the implementation moves behind the typed runtime surface.
- Release gates now exercise TUI, ACP, and JSONL flows against the release
  binary. Publication checks require matching archives, checksums, npm
  tarballs, registry integrity, optional dependency aliases, native binary
  bytes, and a clean installed `orca --version` result.

## Compatibility

No CLI flag or user configuration change is required. `--mode=acp` and the
existing JSONL server protocol keep their external invocation and wire
contracts. Existing sessions remain readable and resume through the durable
runtime-owned state.

## Install

```bash
npm install -g @blade-ai/orca@0.2.55
```

Or install a native release asset:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.2.55 sh
```
