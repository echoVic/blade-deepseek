# Orca v0.3.2

Orca v0.3.2 fixes a terminal crash when launched through the npm wrapper and
adds DeepSeek V4 low reasoning-effort support.

## What Changed

- When launched via Node.js (`stdio:"inherit"`), the inherited terminal file
  descriptors may carry `O_NONBLOCK`. Orca now clears non-blocking flags on
  stdin, stdout, and stderr at startup through a `stdio_guard` module, and
  wraps stdout with a `RetryWriter` that retries `EAGAIN`/`EINTR` as a
  fallback. This eliminates `os error 35` crashes during rapid terminal
  resize on macOS.
- Reasoning effort now supports `low` in addition to `medium` and `high`.
  The TUI slash menu reflects all three levels.
- DeepSeek API requests always include the `thinking` configuration block and
  a correct default `max_tokens` value, matching V4 parameter requirements.
- Empty `reasoning_content` responses no longer produce a spurious replay
  state.

## Compatibility

Existing CLI flags, configuration, saved sessions, JSONL, app-server, and ACP
contracts remain compatible. The `reasoning_effort = "low"` config option is
additive.

## Upgrade

```bash
npm install -g @blade-ai/orca@0.3.2
```

macOS and Linux native installer:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.3.2 sh
```

Windows PowerShell, including workspace sandbox setup:

```powershell
& ([scriptblock]::Create((irm https://orcaagent.dev/install.ps1))) -Version 0.3.2 -SetupSandbox
```
