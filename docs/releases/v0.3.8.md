# Orca v0.3.8

Orca v0.3.8 makes long-running sessions, delegated work, and external tool
connections more recoverable and observable.

## What Changed

- The TUI context footer now shows both the used percentage and the remaining
  token count. Resume replays repeated compactions one-to-one with their saved
  summaries, and interrupted generations persist queued steer input before a
  resume starts.
- Asynchronous subagent results remain durable and can be read completely
  through `subagent_status` result paging with `offset`, `limit`, total length,
  and next-page metadata. Workflow agent rows also expose their full transcript
  path.
- Background shell, subagent, workflow, and main-session tasks publish proactive
  completion, failure, cancellation, and approval notices. Completed tasks tell
  the user when a persisted result is ready for inspection.
- stdio MCP clients reconnect, initialize, and refresh tools after a timeout,
  closed transport, reader shutdown, or failed pipe write, so a later request
  can recover without restarting Orca.
- JSONL transcript appends remain protected by a cross-process file lock. Event
  sequence reservations now add an optimistic writer cursor and reject a stale
  independent writer before it can reuse an already reserved sequence range.
- Workflow launches accept an optional run-level `tokenBudget`. Settled child
  usage, including retries and resumed work, contributes to the shared budget;
  each child reserves available capacity before it starts so concurrent agents
  cannot claim the same tokens. Status output reports total, spent, and
  remaining tokens, including prior spend in resumed background launches.
- `/skills` now opens a searchable `$` picker backed by metadata-only discovery.
  Selected skill references behave as atomic composer tokens. Slash command
  parsing rejects unexpected trailing arguments, while `/status`, `/mode`, and
  the settings menus read the committed runtime state instead of stale config.

## Compatibility

Existing transcripts, workflow drafts, and skill files remain readable. The
new workflow budget and subagent paging fields are optional and backward
compatible. A second process attempting to reserve event sequences from a stale
cursor now receives an explicit error instead of producing an overlapping event
stream.

## Upgrade

```bash
npm install -g @blade-ai/orca@0.3.8
```

macOS and Linux native installer:

```bash
curl -fsSL https://orcaagent.dev/install.sh | \
  INSTALL_DIR=/usr/local/bin ORCA_VERSION=0.3.8 sh
```

Windows PowerShell, including workspace sandbox setup:

```powershell
& ([scriptblock]::Create((irm https://orcaagent.dev/install.ps1))) -Version 0.3.8 -SetupSandbox
```
